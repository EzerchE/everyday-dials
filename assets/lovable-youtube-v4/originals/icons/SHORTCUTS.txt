YOUTUBE STREAM DECK PACK - v4
=============================

SETUP
- Keys: Stream Deck > "Hotkey" action. Set State 1 = <name>.png, State 2 = <name>-pressed.png.
- Turn off the key title (images already contain labels).
- Dials (Stream Deck +): use a dial hotkey plugin (e.g. "Advanced Dial"/"Dial Hotkey").
  Default screen = dial-<name>.png, while turning left = dial-<name>-left.png, right = dial-<name>-right.png
  (only plugins that can change the touch screen image support the left/right images).
- The YouTube tab must be focused (click the video once) for shortcuts to work.
- macOS: use Cmd instead of Ctrl where noted.

Note: "prev-chapter"/"next-chapter" (labels "Previous"/"Next") are the general
versions; use the "-alt" files when you want the button to say "Prev/Next Chapter".
Bonus: number keys 1-9 jump to 10%-90% of the video.
