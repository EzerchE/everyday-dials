VIDEO CONTROLS — V7 / SHORTCUT MAPPING
=============================

SETUP / IMPORTANT CORRECTIONS
- This is artwork, not an installed plugin or profile.
- Use labeled PNGs with the native title disabled; use icon-only PNGs if
  the application renders the label itself. Never show both labels.
- A standard Hotkey is not a two-state press feedback action.
- A Hotkey Switch or Multi Action Switch toggles persistently; this is not
  momentary press feedback. Plugins must set pressed on keyDown and normal
  on keyUp. Dial feedback also needs plugin event handling.
- Focus the YouTube player; shortcuts may type into an active search box.
- Do NOT globally replace Ctrl with Cmd on macOS. Chapters use Option.
- Keyboard punctuation depends on keyboard layout; send the intended
  character (<, >, ?, +) rather than assume a US keyboard scan code.

SOURCES / TEST STATUS
Official reference checked on 21 November 2026:
https://support.google.com/youtube/answer/7631406?hl=en
That page confirms play, mute, seeks, chapter shortcuts, frame steps,
speed, volume, restart/end, search, fullscreen, captions and video jumps.
It does NOT list Theater (T), caption size (+/-) or the exact '?' key
combination. These common mappings are included as compatibility options:
verify them against the current YouTube player and keyboard layout before
shipping. Previous video requires a playlist; chapters require chapters.
No physical keyboard, browser shortcut or Stream Deck hardware end-to-end
checks were performed for this asset delivery.

DIAL IMAGES
normal = static operation description, not a fake current value.
left/right = momentary direction feedback; values remain visible and only the active side is accented.
Reset after the last tick; pressed = held dial press feedback.
pressed = momentary push feedback. Speed push is unassigned ('—').
The full strip reference is illustrative; render each encoder separately.
